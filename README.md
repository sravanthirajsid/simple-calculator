# Python Calculator

A simple command-line calculator built using Python. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

# Technologies Used

* Python 3
* Command Line / Terminal
* VS Code (optional)

# Features

* Addition
* Subtraction
* Multiplication
* Division
* Handles division by zero
* Handles invalid operators

# Setup Instructions

# 1. Install Python

Download and install Python 3 from the official Python website.

# 2. Clone the Repository

Open your terminal and run:

'''bash
git clone YOUR_GITHUB_REPOSITORY_LINK
'''

# 3. Open the Project

'''bash
cd python-calculator
'''

# 4. Run the Program

'''bash
python calculator.py
'''

If your system uses `python3`, run:

'''bash
python3 calculator.py
'''

# 5. Use the Calculator

Enter the first number, operator, and second number when prompted.

Example:

'''text
Simple Calculator

Enter first number: 10
Enter operator (+, -, *, /): *
Enter second number: 5

Result: 50.0
'''
